# Simple-Login-Form
This repository contains a simple webpage to test application security, based on preventing some vulnerabilities found in OWASP Juice Shop.
Web page is based from tutorial at https://www.tutorialrepublic.com/php-tutorial/php-mysql-login-system.php
My understanding of web development is nearly non-existent, with most of my understanding being PHP, which is why the project is PHP.

To run the project, local php and mysql installations are needed. Make sure both the database and webserver are running, then access localhost:portnumber in your web browser. port number is whatever you set it to when running the php server.
